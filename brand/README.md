# Vhaya logo source

`vhaya-logo-mark.svg` is the shared logo source for the Android app and web console. It keeps the original navy, white V, and red forward-arrow identity in a crisp, scalable format.

After editing the SVG, run `pnpm run brand:sync` to regenerate the Android vector/launcher assets and the web favicon from this source. The sync command uses ImageMagick to render the legacy Android launcher PNGs.
